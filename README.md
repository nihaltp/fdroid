# nihaltp's F-Droid Repository

Welcome to my personal F-Droid repository! This repository hosts a collection of open-source Android applications that I have developed. All apps are fully open-source, and if you prefer not to use F-Droid, you can also download them directly from their GitHub release pages.

## 🚀 How to Use This Repo

If you are new to F-Droid, follow these steps to install my apps on your Android device:

1. **Install F-Droid:** First, download and install the official [F-Droid client](https://f-droid.org/) on your Android device.
2. **Add the Repository:** You can add this repository to your F-Droid client in two ways:

   **Method A: Scan QR Code (Easiest)**
   - Open the F-Droid app.
   - Go to **Settings** > **Repositories**.
   - Tap the **+** button at the top.
   - Tap the QR code icon and scan the image below:

   ![F-Droid Repository QR Code](repo/index.png)

   **Method B: Manual Entry**
   - Open the F-Droid app.
   - Go to **Settings** > **Repositories**.
   - Tap the **+** button.
   - Paste the following URL into the "Repository address" field:

     ```text
     https://nihaltp.github.io/fdroid/repo/
     ```

3. **Update & Install:** After adding the repository, refresh your F-Droid repositories. You will now be able to search for and install my apps directly from the client!
